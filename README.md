# Aquarium Shop Website

A responsive static website concept based on the supplied Aquarium Shop business idea board.

## Run locally
Open `index.html` in a browser. Keep the `assets` folder next to it.

## Included
- Responsive navigation and layout
- Products with sample/indicative prices
- Services, target customers, business model and revenue streams
- Supplied concept image used in the 3D design / floor plan section
- Enquiry form demo (does not send or store information)
- Future scope section

## Before publishing
- Replace indicative prices with real prices.
- Add your actual shop location and contact number.
- The enquiry form currently only creates a summary on screen. Connect a backend, form provider or WhatsApp link for real submissions.
- The provided board is a single combined image, so gallery previews reuse the full board rather than separate individual renders.
